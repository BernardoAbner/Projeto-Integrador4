# Rede Clara — Projeto Integrador IV

O Rede Clara simula falhas em uma porta de switch e mostra como o tráfego e os descartes de pacotes ajudam a investigar a causa. A apresentação acompanha um cenário de saturação de banda, do gráfico aos trechos de código responsáveis pelo diagnóstico.
